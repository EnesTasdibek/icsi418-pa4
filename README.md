# Projects, Memberships and User Stories App - Enes Tasdibek
ICSI 418Y Programming Assignment 4. This full-stack web application continues Programming Assignments 1, 2 and 3. Users can sign up and log in, and after logging in they can create software projects, manage project members, and manage a backlog of user stories for each project.

Each project has a name, description, status (Planning, Active or Completed) and a Project Lead selected from the registered users. The Project Lead is automatically added as a member of the project and cannot be removed. Registered users can be added to or removed from a project, and the same user can belong to multiple projects. A user cannot be added to the same project twice.

Each project has a backlog of user stories. A story has a title, a description ("As a [type of user], I want [goal], so that [benefit]."), a priority (High, Medium or Low), a status (To Do, In Progress or Done) and an assigned member. New stories always start as To Do. A story can be assigned to one member of its project or left Unassigned. Stories can be edited, have their status changed, and be deleted after confirmation. A member cannot be removed from a project while they still have stories assigned in that project, including Done stories.

## Technologies
- React (Vite) for the frontend
- Node.js and Express for the backend
- MongoDB with Mongoose

## Database
Collections: `users`, `Projects`, `ProjectMemberships`, `UserStories`.

A UserStories document contains:
- `_id`: generated by MongoDB
- `project_id`: ObjectId of the project the story belongs to
- `title`: story title
- `description`: the user story text
- `priority`: High, Medium or Low
- `status`: To Do, In Progress or Done
- `assigned_user_id`: ObjectId of a project member, or `null` for Unassigned

## Instructions for running the program
1. Create a `.env` file inside the `server` folder with your MongoDB connection string:
   ```
   MONGO_URI=your_mongodb_connection_string
   ```
2. Install dependencies and start the backend server:
   ```
   cd server
   npm install
   node server.js
   ```
   The terminal should show `Server Started at 9000` and `Connected to MongoDB`.
3. In a second terminal, install dependencies and start the React client:
   ```
   cd client
   npm install
   npm run dev
   ```
4. Open the link shown in the terminal (usually http://localhost:5173) in the browser.
5. Sign up or log in. After a successful login, the project section appears. Select a project to manage its members and its story backlog.
